## 本规则是什么

《组方规则》是一套**确定性组方规则**——以《黄帝内经》五行气化模型为体，以《神农本草经》性味理论为器，以《汤液经法》（《辅行诀五脏用药法要》所存其法度）五味所用体系为术，把"从病机到方剂"变成可编程、可审查的逻辑，以再现《伤寒杂病论》组方之逻辑。

**核心结构**：一君二臣三角（君定方向、臣甲同味助之、臣乙克味制之），佐使随兼证权变；五味合化合除、味性分治、反佐配伍、术数补泻、剂量换算、峻烈药制约，层层设卡，输出必附完整审查报告。

**通用型扩展**：除一君二臣外，含二君四臣、三君六臣等整数倍增结构，用于复杂病情及"近者奇之，远者偶之；汗者不以奇，下者不以偶"之精细化运用。

## 已知边界（诚实声明）

本规则是**现有条件下的最优解，而非最终最优**：

- 《桐君采药录》已佚，今人不能如《辅行诀》《伤寒论》一般，把药物精细到**第二层的五行属性**。
- 故本规则守《内经》《本经》精神——**只用药味，不用五行属性**。

**此边界即后来者之接口**：若有来者能补全药物（尤其是常用药）之五行属性，则所出组方必然更精细——v2.0 及以后，留给后来者。

## 版本定位

- **v1.0.0**：通用版。此版本如一盏灯，为医者指明**配方的入口在哪里**——它不是终点答案，而是起点。
- 本规则的目标，是让组方成为**必然**，而非"试试"：病机既定，君臣即定——主结构依理而定（必然方之根），次结构随证而变（化裁之要）。
- 版本演进采用语义化版本；验证状态见《验证状态清单》。
